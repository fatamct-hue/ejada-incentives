# منصة حوافز الإجادة المؤسسية

وزارة الإسكان والتخطيط العمراني — فريق الإجادة المؤسسية في وزارة الإسكان والتخطيط العمراني.

## مكونات المستودع
- `index.html` و`app.js` و`app.css`: واجهة المنصة (تُنشر على GitHub Pages).
- `supabase/schema.sql`: قاعدة البيانات، والصلاحيات وعزل بيانات كل تقسيم على الخادم، وقواعد المنع.
- `vendor/`: مكتبتا Supabase وExcel.
- `brand/`: ضع فيه ملفات الشعار.
- `PROMPT.md` و`reference/`: المواصفات والمعاينة المعتمدة.

## التشغيل لأول مرة
1. **Supabase ← SQL Editor ← New query**: الصق محتوى `supabase/schema.sql` كاملاً، ثم **Run**. تظهر في النتيجة رسالة فيها «رمز تفعيل حساب فريق الإجادة».
2. **Supabase ← Authentication ← Sign In / Providers ← Email**: أوقف **Confirm email**، ثم **Save**.
3. افتح رابط المنصة، واختر «تفعيل حساب جديد»، وأدخل بريدك وكلمة مرور ورمز التفعيل.
4. من «الإعدادات»: أدخل العدد المعتمد للموظفين وأعداد التقسيمات، وأضف المستخدمين، وأرسل لكل مستخدم رمز التفعيل الخاص به.

## النسخ الاحتياطي
من Supabase ← Database ← Backups (يومي تلقائياً في الخطة المجانية لفترة محدودة)، أو من Table Editor ← Export to CSV لكل جدول.

## النقل لاحقاً إلى خوادم الوزارة
- قاعدة البيانات: ملف `supabase/schema.sql` يعمل على أي Supabase (سحابي أو مستضاف ذاتياً).
- الواجهة: ملفات ثابتة تُرفع إلى أي خادم ويب، مع تعديل `SB_URL` و`SB_KEY` في أول `app.js`.
